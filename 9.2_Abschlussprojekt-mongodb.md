# Abschlussprojekt – Spring Boot & MongoDB

**Modul:** NoSQL / MongoDB  
**Zielgruppe:** Lernende Berufsbildung, 2. Jahr  
**Zeitbedarf:** 6 Lektionen  
**Sozialform:** Partnerarbeit (PA)  
**Bewertung:** Code + Dokumentation + kurze Präsentation  

---

## Projektauftrag

Ihr entwickelt zu zweit eine **Spring Boot Applikation** mit **MongoDB** als Datenbank.
Die Applikation soll ein Thema eurer Wahl abbilden und die folgenden Pflichtkompetenzen
nachweisen:

| Pflicht | Beschreibung |
|---|---|
| ORM / Entities | Mindestens **2 Document-Klassen** mit `@Document`, `@Id`, Beziehungen (embedded oder referenziert) |
| Repository | Mindestens **1 Spring Data Repository** mit eigenen Query-Methoden (`@Query`) |
| Aggregation | Mindestens **5 Aggregations-Pipeline** mit `@Aggregation` (z.B. Gruppierung, Summe, Durchschnitt) |
| REST-API | Mindestens **5 Endpoints** (GET, POST, je drei weitere) |
| Dokumentation | Kurze technische Dokumentation (siehe Abgaben) |

---

## Themenvorschläge

  Wählt **ein** Thema – oder schlägt ein eigenes vor (Absprache mit Lehrperson).

---

### Thema 1 – Bibliotheks-Verwaltung
**Idee:** Verwaltung von Büchern, Autoren und Ausleihen.

**Collections:**
- `Book` → Titel, Genre, Jahr, eingebetteter `Author`
- `Loan` → Buch-ID, Lesername, Ausleihdatum, Rückgabedatum

**Aggregation-Idee:**
- Anzahl Ausleihen pro Genre
- Durchschnittliche Ausleihdauer

**Warum geeignet:** Klare 1:N-Beziehung, reale Einsatzszenarien, einfache Testdaten.

---

### Thema 2 – Sportturnierplan
**Idee:** Verwaltung von Teams, Spielen und Ergebnissen eines Turniers.

**Collections:**
- `Team` → Name, Stadt, Spielerliste (embedded Array)
- `Match` → Team A, Team B, Datum, Score

**Aggregation-Idee:**
- Rangliste (Siege/Niederlagen pro Team)
- Tore pro Runde summiert

**Warum geeignet:** Arrays und eingebettete Dokumente gut demonstrierbar, motivierendes Thema.

---

### Thema 3 – Rezept-Plattform
**Idee:** Sammlung von Rezepten mit Zutaten und Nutzerbewertungen.

**Collections:**
- `Recipe` → Name, Kategorie, Zutaten (embedded Array mit Menge/Einheit), Zubereitungszeit
- `Rating` → Rezept-ID, Benutzername, Sterne (1–5), Kommentar

**Aggregation-Idee:**
- Durchschnittliche Bewertung pro Rezept
- Anzahl Rezepte pro Kategorie

**Warum geeignet:** Embedded Documents mit komplexer Struktur, Aggregation sehr praxisnah.

---

### Thema 4 – IT-Supportticket-System
**Idee:** Helpdesk-System für interne IT-Anfragen.

**Collections:**
- `Ticket` → Titel, Beschreibung, Status (`open`/`in-progress`/`closed`), Priorität, erstellt von
- `Comment` → Ticket-ID, Autor, Text, Datum (embedded in Ticket)

**Aggregation-Idee:**
- Anzahl offener Tickets pro Priorität
- Durchschnittliche Bearbeitungszeit geschlossener Tickets

**Warum geeignet:** Sehr praxisnahe App, Status-Enums, eingebettete Kommentare.

---

### Thema 5 – Online-Shop / Produktkatalog
**Idee:** Verwaltung von Produkten, Kategorien und Bestellungen.

**Collections:**
- `Product` → Name, Preis, Kategorie, Lagerbestand, Tags (Array)
- `Order` → Bestelldatum, Kundename, Positionen (embedded Array: Produkt-ID + Menge)

**Aggregation-Idee:**
- Umsatz pro Kategorie
- Top-5 meistbestellte Produkte

**Warum geeignet:** Komplexe verschachtelte Dokumente, aggregierter Umsatz sehr realistisch.

---

### Thema 6 – Lernkarten-App (Flashcards)
**Idee:** Digitale Lernkarten für Prüfungsvorbereitung.

**Collections:**
- `Deck` → Titel, Fach, Erstellungsdatum, Karten (embedded Array: Frage + Antwort)
- `LearnSession` → Deck-ID, Benutzer, Datum, Richtig/Falsch-Anzahl

**Aggregation-Idee:**
- Lernfortschritt pro Benutzer (% richtig)
- Welche Decks am häufigsten geübt werden

**Warum geeignet:** Embedded Arrays gut sichtbar, Lernende kennen das Konzept aus eigener Erfahrung.

## Technische Anforderungen

```
Java 17+
Spring Boot 3.x
Spring Data MongoDB
MongoDB (lokal oder Atlas Free Tier)
Maven oder Gradle
```

**Minimale Projektstruktur:**
```
src/
 └── main/
      ├── java/
      │    └── com.beispiel.projekt/
      │         ├── model/          ← @Document Klassen
      │         ├── repository/     ← MongoRepository + @Query
      │         ├── service/        ← Businesslogik + @Aggregation
      │         └── controller/     ← REST-Endpoints
      └── resources/
           └── application.properties  ← MongoDB-Verbindung
```

**application.properties Beispiel:**
```properties
spring.data.mongodb.uri=mongodb://localhost:27017/projektdb
spring.data.mongodb.database=projektdb
```
